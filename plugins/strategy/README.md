# Strategy

Skills for deciding where to play and how to win: market and competitive analysis, business models, go-to-market, pricing, customer discovery, and turning strategy into product direction.

Install with `claude plugin install strategy@strategic-operator`, then call any skill directly as `/strategy:<skill-name>` or just describe what you need.

Some skills can pull from connected tools like Slack or Jira; see [CONNECTORS.md](CONNECTORS.md). A few of borghei's skills reference [SHARED_OUTPUT_SCHEMA.md](SHARED_OUTPUT_SCHEMA.md) for their Python tools' output formats. Licenses for borrowed work are in [LICENSES/](LICENSES/).
