# Positioning

Decide where to play and how to win — market frameworks (Porter's, SWOT, Ansoff), business-model canvases, ICP, and go-to-market strategy.

Install with `claude plugin install positioning@strategic-operator`, then call any skill directly as `/positioning:<skill-name>` or just describe what you need.

Some skills can pull from connected tools like Slack or Jira; see [CONNECTORS.md](CONNECTORS.md). A few of borghei's skills reference [SHARED_OUTPUT_SCHEMA.md](SHARED_OUTPUT_SCHEMA.md) for their Python tools' output formats. Licenses for borrowed work are in [LICENSES/](LICENSES/).
